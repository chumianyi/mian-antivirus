# 眠. (Mian Antivirus)

一款功能丰富的Android杀毒软件，支持Shizuku/基础/强杀/Root四种授权模式。

## 功能特性

### 授权模式
- **基础模式**：无障碍权限 + 悬浮窗权限
- **强杀模式**：无障碍 + 悬浮窗 + Shizuku
- **Shizuku模式**：Shizuku完整功能
- **Root模式**：Root权限（日常不建议开启）

### 核心功能
- **扫毒**：自动连接病毒库，扫描手机所有文件，检测常见木马病毒
- **急救箱**：紧急时刻强扫系统，自动清除所有前台和后台程序
- **安全防护**：实时守护，支持通知栏/音量键/摇晃三种触发方式
- **音量保护**：监控应用强制拉满音量，自动禁止该应用

### 其他功能
- 应用管理（卸载/冻结/查看权限）
- 进程管理（查看/结束进程）
- 权限管理（危险权限检测）
- 缓存清理
- 电池优化
- 网络监控

## 技术栈
- Kotlin原生开发
- Material 3设计
- minSdk 24, targetSdk 34
- Shizuku API
- libsu (Root)
